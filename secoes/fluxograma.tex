O fluxograma da Figura \ref{fig:fluxograma_software} representa a lógica de execução do software embarcado. O sistema parte da escolha do usuário na interface web entre os que seguem abaixo:

\begin{itemize}
    \item \textbf{Desligado:} o LED amarelo é aceso e o sensor é desligado, interrompendo a coleta de dados;
    \item \textbf{Automático:} o LED azul é aceso e o sensor coleta e exibe os dados continuamente. Quando o limite for ultrapassado, o buzzer é ativado juntamente com um alerta automático, sem a necessidade de intervenção do usuário;
    \item \textbf{Ligado:} o LED verde é aceso e o sensor coleta e exibe os dados em tempo real. Quando o limite for ultrapassado, ativa o buzzer de forma automática, porém envia um alerta com duas opções de alteração de modo.
\end{itemize}
