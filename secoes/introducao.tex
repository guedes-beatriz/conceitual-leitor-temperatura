\section{Introdução}

Este documento apresenta a proposta de desenvolvimento de um Leitor de Temperatura e Umidade para monitoramento ambiental, conforme solicitado pelo cliente. O sistema tem como objetivo coletar dados em tempo real e disponibilizá-los de forma eficiente e intuitiva por meio de uma interface web.

O sistema irá utilizar um sensor de temperatura e umidade integrado a um microcontrolador com suporte à rede sem fio, operando em três modos distintos: Desligado, Ligado e Automático. Além disso, a indicação visual do modo ativo será realizada diretamente no hardware através de LEDs dedicados.

A interface web permitirá a visualização dos dados de temperatura e umidade em tempo real, além de disponibilizar botões interativos para a alternância entre os modos de operação, garantindo o controle total do sistema remotamente. Com isso, o sistema é projetado para ser confiável, preciso, eficiente e de fácil utilização para o usuário.
